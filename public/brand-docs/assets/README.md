# Logos

The mark is a coin cut by a horizon and five furrows: the till and the tilled field in one shape.

- `tillwright-wordmark.svg`: mark in `field` (#1F4D36) with the name in `ink` (#22201B). Default on `surface` and `surface-raised`.
- `tillwright-wordmark-reverse.svg`: mark in `rye` (#E9B949) with the name in light (#F3F5EE). Use on dark grounds, `field` or photography.
- `tillwright-mark.svg`: mark alone in `field`. Favicon, app icon, invoice header, small spaces.
- `tillwright-mark-reverse.svg`: mark alone in light (#F3F5EE), on `field` or dark grounds.
- `tillwright-mark-currentcolor.svg`: mark drawn with `currentColor`, for inline SVG that should follow CSS `color`. As an `<img>` it renders black.

Clear space around the logo equals the height of the horizon gap times four (about a quarter of the mark's width). Minimum size: mark 16px, wordmark 96px wide. Never recolour the furrows separately, stretch the mark, or set the name in another face.
